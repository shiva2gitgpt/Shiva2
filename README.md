# Shiva 2.0

Persistent multi-AI platform developed by SHIVA.

## Current stack
- Frontend: `index.html`
- Backend: `server.js`
- Runtime: Node.js / Express
- Database: PostgreSQL
- AI providers: Gemini + Groq
- Authentication: session tokens + scrypt password hashing

## Development rule
ChatGPT performs code design, editing and verification. Termux is used only as the Git transport layer for pull/push operations.
